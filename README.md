# re-me (v.3.1-11-2026)

"re: me – Server" automatically responds to incoming SMS with a matching message from its dataset.<br>
"re: me – IOS" is a keyboard extension that recalls users’ previously sent messages as new replies.<br>
"re: me – Android" is a keyboard extension that recalls users’ previously sent messages as new replies.
